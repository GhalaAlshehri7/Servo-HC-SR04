# Servo Motor with HC-SR04

## Description
This project controls a Servo Motor using an HC-SR04 Ultrasonic Sensor and Arduino Uno.

## Components
- Arduino Uno
- Servo Motor
- HC-SR04 Ultrasonic Sensor
- LED (Optional)
- 220Ω Resistor
- Jumper Wires

## Working Principle
- If an object is detected at a distance of 10 cm or less, the servo rotates to 90° and the LED turns ON.
- If the object moves farther than 10 cm, the servo returns to 0° and the LED turns OFF.
